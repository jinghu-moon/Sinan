# 0.8.7：全部 TUI 弹窗统一设计

七类 TUI 弹窗统一使用 Nord 真彩色、圆角外框、内边距、标题与说明、可滚动内容区和固定操作底栏。此版本调整 TUI；Explorer 内的系统任务对话框继续采用原生系统样式。

## 界面

- 标签层级、目录规则、保护与外观、目录入口使用同一套圆角输入框：背景常驻、左右留白、青色聚焦、蓝色悬停；非法层级显示红框。标签与占位提示分离，保留中文编辑、多行模式与快捷键录入。
- 选择项以带背景的完整文字块排列，空间不足时整项换行。方向键、鼠标选择，Tab／Shift+Tab 切换控件。复选项使用 ✓／○，不加方括号。
- 表单按用途分组；外观设置分为目标、文字字体、图标、浅色背景／文字、深色背景／文字。宽版部分字段并列，窄版纵向滚动。类别与草稿预览在顶部，操作按钮在底部。
- 目录入口包含目录与别名、快捷键、显示方式及草稿预览。重新打开编辑器时回到首个控件。
- 确认框突出操作影响，删除时显示对象、批量操作时显示数量。默认聚焦“取消操作”，直接回车取消；切换到“确认执行”才提交。
- 帮助按导航、编辑、运行状态分组。帮助与结果详情支持 ↑↓、PgUp／PgDn、Home／End 和鼠标滚轮，长报告末尾仍可访问，底栏保持可见。路径测试结果突出计算标题。
- 应用前验证与草稿保存逻辑保持，错误显示在底栏上方。中文操作按钮统一四字；中英文文案及最小 72×24 终端适配。

## 真机验收

```powershell
Set-Location 'D:\100_Projects\110_Daily\test2'
$tt = (Resolve-Path '.\build\package-v0.8.7\bin\tabtail.exe').Path
$data = Join-Path $PWD 'build\manual-v087-data'
& $tt --data-dir $data tui --lang zh-CN
```

1. F1 查看帮助，测试方向键、滚轮、翻页、Home／End；底部“关闭窗口”始终可见，Esc 退出。
2. F3 → 新增规则：检查中文输入、多行路径、层级预览与错误反馈。
3. F8 打开功能设置：依次选择外观、快捷键、通知、恢复。Tab 遍历字段，观察内容随焦点滚动；检查类别栏与应用／重载／取消按钮固定显示。外观目标切换到目录外观规则后检查规则字段。
4. F9 → 新建入口：检查输入框、选项换行、复选框及预览；录入组合键，确认焦点、输入法和鼠标定位正常。
5. F6 → 重启桌面，检查确认框的影响说明，直接 Enter 应取消。仅验收界面时不要选择“确认执行”。
6. F6 → 运行诊断，检查原始报告的换行、滚动、末行与关闭按钮。目录规则页测试路径后检查计算标题。
7. 已有代理提供标签时，F2 → 编辑标签，检查层级输入、非法值保留弹窗与预览。
8. 分别在 110×36 和 72×24 检查上述界面，F7 切换英文，确认草稿保留、按钮完整、底栏可见。

启动独立界面和预览无需启用定制或重启 Explorer。已有代理的原路径更新方式见 [0.8.4](testing-v0.8.4.md)。

## 自动验证

```powershell
cmake --build build/msvc-lifecycle --config Release --parallel 6
ctest --test-dir build/msvc-lifecycle -C Release --output-on-failure
```

测试实际生产组件树，覆盖全部七类弹窗的中英文宽窄布局、固定底栏、各外观字段焦点可见、重新打开时的焦点、非法层级拒绝提交、确认默认取消、帮助／长诊断的首页与末页，以及原有快捷键录入和输入线程隔离检查。

`build/msvc-lifecycle/tui-artifacts/*-dialogs-*.cells.json` 为单元格预览源，可用 `tools/render-tui-snapshot.py` 转为 PNG。实际 Windows Terminal 的字体、输入法候选框与鼠标手感需真机确认。
