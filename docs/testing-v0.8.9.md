# 0.8.9：工具页卡片布局

F6 工具页与设置页采用同一套 Nord 真彩色、圆角分组卡片、背景按钮、留白与限宽布局。中文操作按钮统一四字。

- 批量操作：选择固定、独立保护、目录锁定，再选择开启／关闭，无需输入 pin / protect / lock 或 on / off。显示当前筛选的标签数，范围沿用标签页的路径与状态筛选。没有匹配标签时应用禁用，请求处理中禁止重复提交。
- 标签存档：保存标签、恢复标签、查看存档集中排列，并说明用途。
- 诊断与帮助：运行诊断、查看帮助、功能设置集中排列。
- 运行维护：重启桌面、退出代理独立分组，红色按钮搭配影响说明；继续使用确认弹窗且默认聚焦取消。打开页面或预览不会执行维护动作。
- 批量确认冻结当时的目标 ID、类型、状态；确认框显示数量和操作，确认后提交这一份请求。
- 至少 120 列时左侧操作、右侧运行状态和策略概览，总宽度最多 148 列。右侧不再使用占满高度的空框。较窄时单列排列，状态卡片在操作之后；Tab 聚焦可滚动到每个按钮。
- 全局设置页共享同一套页面卡片组件，七类弹窗与之前的输入线程隔离修复保留。

## 真机验收

```powershell
Set-Location 'D:\100_Projects\110_Daily\test2'
& '.\build\package-v0.8.9\bin\tabtail.exe' --data-dir '.\build\manual-v089-data' tui --lang zh-CN
```

1. F6 检查四组卡片、选项与四字按钮。最大化终端后内容宽度受限并居中；右侧运行状态与策略紧凑显示。
2. 没有标签时“批量应用”应禁用。有代理提供标签时，F2 输入路径筛选，再 F6 核对目标数量。
3. 用方向键或鼠标选择操作类型与目标状态，点击批量应用。核对确认框中的数量与动作；直接 Enter 应取消。仅验收界面无需确认应用。
4. Tab／Shift+Tab 按批量、存档、诊断、维护顺序移动。72×24 下每个聚焦按钮都应完整可见。
5. 查看帮助、功能设置、运行诊断，确认对应弹窗仍正常。保存／恢复标签会执行其操作，按需测试。
6. 打开重启桌面与退出代理的确认框，检查默认取消；Esc 关闭，不执行维护。
7. F7 切换英文，检查选项、提示和按钮；所选批量类型与状态保持。
