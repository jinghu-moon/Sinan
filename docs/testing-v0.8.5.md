# 0.8.5：四字按钮与状态切换

所有中文操作按钮统一为四个汉字，保留背景和左右留白。导航标签、单选选项、复选框和说明文本使用各自的语义，不属于操作按钮；英文使用自然动作短语。

| 当前状态 | 按钮文字 | 按钮外观 |
| --- | --- | --- |
| 未固定 | 固定标签 | 普通深灰背景 |
| 已固定 | 取消固定 | 黄色背景、深色加粗文字 |
| 未独立保护 | 保护标签 | 普通深灰背景 |
| 已独立保护 | 解除保护 | 绿色背景、深色加粗文字 |
| 未锁定目录 | 锁定目录 | 普通深灰背景 |
| 已锁定目录 | 解除锁定 | 紫色背景、深色加粗文字 |
| 规则已停用 | 启用规则 | 普通深灰背景 |
| 规则已启用 | 停用规则 | 绿色背景、深色加粗文字 |

每个按钮仅显示当前可执行的一个动作。标签按钮分别读取 `pinned`、`protected`、`locked`，不以有效关闭保护代替独立保护状态。因此，固定导致关闭保护生效时，“保护标签”仍表示可以额外开启独立保护。

切换所选标签、中英文切换和后台快照刷新都会更新按钮文字和外观。提交期间禁用按钮，保留上次已收到的状态；响应失败不假定开关已生效；响应携带的新快照可反映部分成功后的实际开关。无可选对象时禁用。

其他中文按钮按具体操作命名，例如“编辑标签”“编辑规则”“创建规则”“自动匹配”“应用设置”“取消操作”“确认执行”“刷新界面”。原“重启资源管理器”按钮缩写为“重启桌面”，确认框仍完整说明 Explorer、桌面、任务栏和文件夹窗口的关闭影响。

## 真机验收

```powershell
Set-Location 'D:\100_Projects\110_Daily\test2'
$tt = (Resolve-Path '.\build\package-v0.8.5\bin\tabtail.exe').Path
$data = Join-Path $PWD 'build\manual-v085-data'
& $tt --data-dir $data tui --lang zh-CN
```

1. 逐页检查按钮及编辑框、确认框中的操作按钮，中文均为四个字，固定／保护／锁定不再同时显示正反动作。
2. 在现有已适配的定制环境中，选择未固定标签，点“固定标签”；刷新结果后应变为黄色“取消固定”。取消后恢复普通“固定标签”。保护和锁定同样复测。
3. 两个标签使用不同状态，在列表中来回选择，按钮应立即跟随所选标签。仅固定时，“保护标签”不应错误变成“解除保护”。
4. 请求处理中不能重复点击；失败后按返回快照显示状态。F7 切换语言不改变状态。缩到 72×24 后按钮正常排列与换行。
5. F3 中规则启用时显示“停用规则”，停用后显示“启用规则”。

新目录使用独立配置；已有配置的保留及原路径更新方式见 [0.8.4 升级步骤](testing-v0.8.4.md)。不要同时运行旧版代理，旧版全局键盘钩子仍可能拖慢输入。

## 自动验证

```powershell
cmake --build build/msvc-lifecycle --config Release --parallel 6
ctest --test-dir build/msvc-lifecycle -C Release --output-on-failure
```

TUI 检查遍历生产组件树的中文操作按钮并校验四字文案，验证三个标签按钮的请求方向、选中对象、状态配色、异步失败、收到快照后切换、语言切换及处理中不重复提交。规则状态和中英文宽窄布局也受覆盖。测试不修改 Explorer。
