# 0.8.8：全局设置页统一表单

F4 设置页重设计为标题显示、标签宽度、界面语言三张圆角卡片。分组有独立操作按钮，中文操作按钮保持四字，采用 Nord 真彩色。

- 层级、固定宽度、最小／最大宽度使用带背景、内边距和焦点边框的圆角输入框。层级非法、宽度超限或最小宽度大于最大宽度时，边框标红，应用验证拒绝提交并保留草稿。
- 分隔符、宽度模式、语言选择采用可换行的完整选项块。键盘顺序与视觉顺序一致，Tab／Shift+Tab 跨分组，方向键或鼠标选择选项。
- 至少 120 列时，左侧表单、右侧预览与运行状态；内容总宽度最多 148 列。较窄终端使用单列，精简标题预览固定在表单上方。内容随焦点滚动，大窗口不再有两块铺满窗口高度的空框。
- 预览突出标题、路径、影响数量，标注尚未保存及更高优先级的规则／标签覆盖。观察或离线时说明保存配置后需启用定制才修改 Explorer 标签。
- 语言选择立即预览，保存按钮保存偏好。标题与宽度各自显示草稿状态；重载标题设置仅重载层级与分隔符，保留独立宽度草稿；重载宽度仍保留标题草稿。

## 真机验收

```powershell
Set-Location 'D:\100_Projects\110_Daily\test2'
& '.\build\package-v0.8.8\bin\tabtail.exe' --data-dir '.\build\manual-v088-data' tui --lang zh-CN
```

1. F4：检查三张卡片、数字输入框、四字操作按钮。放大 Windows Terminal 后，内容保持居中且宽度受限。
2. 层级改为 3，预览即刻更新；改为 0 或非数字，输入框标红，点击应用显示错误并保留内容。
3. 切换固定宽度、随内容模式，检查字段按模式显示。输入 120／480，随后改成 500／100，确认非法范围不能提交。
4. 同时修改层级与宽度，点击重载显示，确认仅标题设置回到保存值，宽度草稿保留；再重载宽度。
5. 选择英文、简中，保存语言；Tab 顺序应为标题设置、宽度设置、语言设置。
6. 将终端调整为 72×24、110×36 和大窗口。输入框、宽度操作和语言保存都应能通过 Tab 滚动到可见位置。宽版预览标题、路径和运行提示应清晰换行。

仅检查界面不需重启 Explorer。独立数据目录使用默认配置；已有配置／代理的更新方式见 [0.8.4](testing-v0.8.4.md)。
